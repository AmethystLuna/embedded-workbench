# Security Policy

## Supported Versions

This project is in active development. The latest release on the `master` branch is supported; older releases receive security fixes on a best-effort basis.

| Version | Supported |
|---------|-----------|
| latest (master) | ✅ |

## Reporting a Vulnerability

Please report security vulnerabilities privately by opening a GitHub Security Advisory:

1. Go to <https://github.com/AmethystLuna/embedded-workbench/security/advisories/new>
2. Describe the vulnerability, affected versions, and a minimal reproduction.

Alternatively, email the maintainer through the GitHub profile contact link. Do **not** open a public issue for security findings.

You can expect an acknowledgment within 3 business days and a fix or mitigation plan within 14 days.
